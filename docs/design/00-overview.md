# 00. 概要 — 汎用ピクセルキャラクタージェネレーター（仮称: PixelForge）

対象読者: 本ツールの実装者。
関連: `agents_app`（Agent Village）— 本ツールは独立した汎用ソフトとして設計するが、生成物をAgent Villageのキャラクター画像として利用できる仕様にする（`05-agent-village-integration.md`参照）。`../../ani_convert_app`（PixelAnimator、仮称）— 本ツールが生成した複数アングルのピクセルキャラクター（`06-multi-angle-input.md`）を入力として、まばたき・歩行の差分フレームを生成する別ソフト。

**実装状況**: 設計のみ（未実装）。

---

## 1. これは何か

- 任意のキャラクター画像（写真・イラスト・背景ありの画像を含む）を読み込ませると、自動的にレトロ風ドット絵（ピクセルアート）キャラクター画像を生成するスタンドアロンのソフト。
- **Agent Village専用ではなく、汎用的に「画像→ピクセルキャラ」変換ができるツール**として設計する。Agent Villageはその応用先の1つという位置づけであり、依存関係は逆向き（PixelForge → Agent Village）にはしない。
- 生成物はAgent Villageの既存の差し替え仕様（PNG・正方形・16〜128px・300KB以下、`public/js/hud.js`のアップロード制約）にそのまま適合させ、手動アップロード・直接連携のどちらでも取り込めるようにする。

## 2. 背景・動機

- Agent Villageのキャラクターは現状、プレースホルダー矩形か、ユーザーが手作業で用意したPNG画像のいずれか。「役職ごとにフルスクラッチでスプライトを描かない」という`01-visual-concept.md`の方針はあるが、そもそも「自分の好きな画像からキャラクターを作る」体験自体がまだ無い。
- 変換方式についてはユーザーと合意済み：**コアは決定論的な画像処理パイプライン**（無料・オフライン・出力がAgent Villageの仕様に必ず適合する）とし、AI生成による高品質化は将来のオプション拡張として設計だけ用意する。
- さらにユーザーから明確な要望があった：**入力画像に背景が混ざっていても、自動で背景除去してキャラクターのみを抽出することで変換精度を上げたい。** この要望を満たすため、パイプラインの最初の段階に「被写体抽出（背景除去）」を明示的なステージとして組み込む（`02-conversion-pipeline.md` §2①）。

## 3. スコープ

### やること

- 画像アップロード→自動処理→プレビュー→パラメータ調整→エクスポート、という一連のUIを持つローカルWebアプリ（Agent Villageと同じ形態、`01-architecture.md`参照）。
- 背景除去→自動トリミング/中央寄せ→ダウンサンプリング→減色/パレット量子化→輪郭強調→書き出し、という決定論的パイプライン（`02-conversion-pipeline.md`）。
- **3段階のフェーズで使える入力設計**（`06-multi-angle-input.md`）: フェーズ1＝正面のみ（必須。既存のAgent Villageエージェントアイコンとしてもそのまま使える）、フェーズ2＝正面＋斜め（推奨。斜めはAgent Village上での移動表示の基本アングルになる）、フェーズ3＝正面＋斜め＋横向き＋後ろ向き（フル）。1枚の画像から他アングルを自動生成することはしない（無い視点情報を捏造しないという方針）。
- Agent Villageへの2通りの連携：手動エクスポート/アップロード、直接送信（`05-agent-village-integration.md`）。
- `ani_convert_app`（PixelAnimator）向けの複数アングル出力（キャラクターアセットバンドル、`06-multi-angle-input.md` §5）。

### やらないこと（明示的にスコープ外）

- AI生成（拡散モデル等）によるスタイル変換そのもの。今回は決定論的パイプラインのみを実装し、AI拡張は将来のオプションとして設計上の差し込み口だけ用意する（`01-architecture.md` §4）。
- **1枚の画像から未提供のアングルを自動生成すること**（例: 正面写真だけから後ろ姿を生成する）。これは新しい視点情報を捏造する処理であり、決定論的パイプラインの範囲を超えるため今回は行わない（`06-multi-angle-input.md` §1）。
- 動きのあるアニメーション自体の生成（まばたき・歩行差分）。これは別ソフト`ani_convert_app`の担当（`../../ani_convert_app/docs/design/00-overview.md`）。本ツールは各アングルの静止画を作るところまで。
- Agent Village以外の外部ツールとの連携。

## 4. 名称

本設計書内では仮称として **PixelForge** と呼ぶ。実装時に正式名称を決めてよい。
